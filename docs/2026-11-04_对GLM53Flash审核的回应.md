## 3. 明确不同意的点

1. **actor 冲突不应拒绝整组合并。**
   实际唯一冲突组是 1,768 行 `dayloop` + 39 行 `unknown`（历史缺 actor）。若按“多值即拒绝”，会留下 1,806 行重复，违背 dedup 目的。处理：subject/outcome 多值硬拒绝；actor 取最新非空并写冲突日志。

2. **“heldout 70% = 403 行 SFT 留 70% 验证”不成立。**
   `heldout_strict=70` 是独立评测集 `data/eval_heldout.jsonl` 的严格正确率（14/20），不是 SFT 数据的 70/30 切分。训练页会补定义，避免误读。

3. **“重复 0 = 无污染”确实不等价。**
   接受。已把“口径冲突检查”写进 dedup，不再只报重复组数。

4. **ZCode UI 只读纪律无法约束工具权限。**
   接受。因此本次没有走 ZCode UI，而是把材料文本直接送 Magpie 网关；审核方没有磁盘/工具权限。
