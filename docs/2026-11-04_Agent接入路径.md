# Agent 接入路径（2026-11-04）

## OpenCode

- 记忆查询/召回：MCP `ctl_memory`
  - `action=query` 全库（可指定 subject）
  - `action=recall` 结构化召回（默认 agent 仓）
  - `action=stats` 计数
- 训练/策略：VS Code `记忆引擎 → 训练`
- 服务：`http://127.0.0.1:28894`（service.json）
- 代理：`http://127.0.0.1:8782`（VS Code 面板打开时）

## ZCode

- 独立审核：ZCode UI / `zcode.cjs` TUI
- 模型：`GLM-5.3-Flash`（托管，不可微调）
- 适用：低频审核、种子数据、交叉验收
- 记忆：MCP `dsh-memory-readonly`
- 额度弹窗：选“切换免费额度”

## DeepSeek Harness

- 独立验收：`<USER_HOME>\.codex\mcp\dsh_memory_mcp.py`
- 包装层：`<ADAPTER_ROOT>\mcp\dsh_memory_readonly_mcp.py`
- 记忆：只读事件流/知识库；写入走 CLI

## VS Code / AgentStation

- 记忆库：底部面板 `记忆库`
- 记忆引擎：底部面板 `记忆引擎`
  - 体检 / 记忆条目 / 知识树 / 理论图谱 / 训练
- 命令：
  - `AgentStation: 打开记忆引擎（面板）`
  - `AgentStation: 在编辑器中打开记忆引擎`
- 训练页：
  - Ollama 状态/模型
  - 训练路径与日志
  - 策略评测（`k/floor`）
  - Agent 调用链

## CLI（唯一写入口）

```powershell
$env:PYTHONPATH='<AGENTCTL_ROOT>\src'
python -X utf8 -m agentctl.memory stats
python -X utf8 -m agentctl.memory backup --keep 14
python -X utf8 -m agentctl.memory dedup --dry-run
python -X utf8 -m agentctl.memory dedup
python -X utf8 -m agentctl.memory tune
python -X utf8 -m agentctl.memory compact --rebuild-segments
python -X utf8 -m agentctl.memory query "关键词" --k 5
```

## 约束

- 读事件流受 `_启用记忆_点名.md` 闸门控制
- 写入只允许追加，不改删
- 训练/策略变更必须先备份、可回滚
- GLM-5.3-Flash 不微调，只做 teacher/judge
