# 60 秒 demo 分镜脚本

> 目标：让一个没听过项目的人在 60 秒内看懂“能动手、会拦、会验、能回放、能急停”。
> 原则：真实窗口、真实拒绝、不剪辑造假；可以加速等待，但不能跳过步骤。

## 录制前准备

- Windows 11，1920×1080，100% 或 150% 缩放都录一条
- 安装最新 v0.1.2，确认 `agentctl status` 正常
- 准备两个窗口：记事本（目标）+ 另一个窗口（干扰）
- 准备一个测试文件：`demo.txt`
- 清空授权状态，确认默认拒绝
- 关闭无关通知、聊天软件、隐私内容
- 录屏 1080p 60fps，显示鼠标点击高亮

## 分镜

| 时间 | 画面 | 旁白/字幕 |
|---|---|---|
| 0–8s | 桌面全景，屏幕四周亮起 AgentCtl 边框 | “AI 已经能点你的桌面。问题是：它点错了怎么办？” |
| 8–20s | Agent 试图在记事本点“保存”，但目标窗口不是记事本 | “目标窗口不匹配，这一下根本不会发出去。” |
| 20–30s | 屏幕弹出授权窗口，人手点“允许” | “装完默认全拒。你本人点允许，它才能动手。” |
| 30–42s | Agent 点中“保存”，画面变化 | “动作发出去不算成功；画面变了才算。” |
| 42–52s | 显示三态判词“生效”，前后截图并排 | “前后截图 + 三态判词：生效 / 确认没变 / 没测出来。” |
| 52–62s | 打开时间线，展示哈希链和回放 | “每一步都有哈希链，改一个字都能查出来。” |
| 62–72s | 按 `Ctrl+Alt+Home`，边框熄灭 | “一个键，全部停下。” |
| 72–80s | 仓库地址 + 一句话 | “computer-use-gate：Windows 桌面 Agent 的安全闸。” |

## 录制命令建议

```powershell
# 1. 确认默认拒绝
& "$env:LOCALAPPDATA\AgentCtl\agentctl.cmd" status

# 2. 录屏可用 Windows + G，或 OBS
# 3. 录完后压缩 GIF（≤5 MB），放到 assets/demo-60s.gif
```

## 输出

- `assets/demo-60s.mp4`：完整版，放 README 或 Release
- `assets/demo-60s.gif`：≤5 MB，放 README 第一屏
- `assets/demo-60s-poster.png`：视频封面

## 验收

一个陌生人看完后能回答：

- [ ] 它拦的是“错误窗口/错误目标”，不是所有点击
- [ ] 它默认拒绝，需要本人授权
- [ ] 它会验证动作是否生效
- [ ] 它有截图、哈希链、回放
- [ ] 它能一键急停
- [ ] 它不需要显卡

## 不要做

- 不要用剪辑把“失败”剪成“成功”
- 不要隐藏授权弹窗
- 不要用真实账号/真实支付/真实删除
- 不要把“动作发出去”说成“成功”
- 不要超过 90 秒；第一版目标 60 秒
